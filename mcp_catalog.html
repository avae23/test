MCP-серверы для создания игры / приложения

Поиск оркестратором: 13 категорий реестра Claude + 4 области open-source (GitHub). Open-source пункты найдены агентами и не проверены лично — перед установкой смотрите код: сторонний MCP получает доступ к вашей машине.

Для iOS-серверов нужен macOS с Xcode.
